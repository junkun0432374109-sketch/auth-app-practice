# auth-app-practice

## 概要

COACHTECH 教材 Tutorial 10-1「認証機能 ハンズオン演習」で作成した成果物です。
Laravelを使って、ユーザー登録、ログイン、ダッシュボード表示、ログアウトができるシンプルな認証アプリを作りました！

## 使用技術

- PHP 8.x
- Laravel 10.x
- MySQL
- Docker / Laravel Sail

## 学んだこと

- ユーザー登録画面やログイン画面から、入力したデータをPOST送信して動かす仕組みが分かりました。
- 登録したユーザーの情報をデータベースに保存して、ログアウトまで安全にセッション管理する流れを勉強できました。
- 未ログインの人が勝手にダッシュボードを見られないように、middlewareでアクセス制限をかける方法を学びました

## 動作確認

1. Docker（Laravel Sail）を立ち上げます。
2. ブラウザで `http://localhost/register` にアクセスしてユーザー登録を行います。
3. 登録完了後、自動でダッシュボード画面が表示されることを確認します。
4. 「ログアウト」ボタンを押して、ちゃんとログイン画面（`http://localhost/login`）に戻るか確認します。
